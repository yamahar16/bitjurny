# 하루상식 — 출시 가이드

앱 코드, 문제 182개(사실 확인 완료), 로고, 스크린샷, 콘솔 입력 문구, 업로드할 번들 파일까지 모두 준비돼 있어요.
**아래 "직접 하셔야 하는 일"만 하시면 출시돼요.** (토스 본인 계정이 필요해서 대신할 수 없는 단계예요)

---

## 직접 하셔야 하는 일 (약 30분 + 검수 대기)

### 1. 콘솔 가입 & 워크스페이스 만들기 (5분)
- https://apps-in-toss.toss.im 접속 → 토스 앱으로 로그인 (만 19세 이상, 본인 명의 토스 계정)
- 워크스페이스 이름: 아무거나 (예: `하루상식`)
- 제작자 이름 (10자 이내, 앱 상세에 노출): 예) `하루상식팀`

### 2. 앱 등록 (3분)
'앱' → '+등록하기'
| 항목 | 입력값 |
|---|---|
| 앱 이름 | `하루상식` |
| 영문 이름 | `Haru Sangsik` |
| appName | **`harusangsik`** (등록 완료, 코드도 이 값으로 맞춰 두었어요) |
| 앱 유형 | **비게임** |


### 3. 번들 업로드 (2분)
'앱 출시' → '등록하기' → 앱 번들에 **`harusangsik.ait`** 파일 업로드
- 파일 위치: **`apps-in-toss/release/harusangsik.ait`** (GitHub 브랜치에서 바로 내려받을 수 있어요)
- 직접 빌드하려면: Node.js 24 이상 설치 → `cd apps-in-toss/app && npm install && npm run build`

### 4. 토스앱 테스트 (10분) — 필수
업로드 후 '토스앱 테스트' → QR 코드를 휴대폰으로 스캔 → 아래 확인
- [ ] 첫 화면에 오늘의 문제가 보인다
- [ ] 보기를 누르면 정답/오답과 해설이 나온다
- [ ] 미니앱을 완전히 닫았다가 다시 열어도 푼 기록이 남아 있다
- [ ] '친구에게 이 문제 내기' → 공유 창이 뜬다
- [ ] '도장 달력 보기' → 달력에 오늘 기록이 보이고, 뒤로가기로 돌아온다
- [ ] 첫 화면에서 뒤로가기(안드로이드 백버튼 포함) → 미니앱이 닫힌다
- [ ] 결과 화면 아래 광고(테스트 광고)가 보인다 — 안 보여도 출시엔 문제없어요

문제가 있으면 '더보기(⋯) → 웹 디버그 툴즈 → Log' 화면을 캡처해서 보내 주세요.

### 5. 앱 정보 입력 & 검수 요청 (10분)
아래 [콘솔 입력 문구](#콘솔-입력-문구)를 그대로 복사해서 넣고 '검토 요청'을 누르면 끝이에요.
검수는 영업일 기준 2~3일 걸려요. 승인되면 '출시하기'를 눌러 주세요.

**상세 설명**
```

로그인이나 개인정보 입력 없이 바로 이용할 수 있어요.
```

## 출시 후 (선택)

### 실제 광고 수익 켜기
1. 콘솔 → 인앱 광고 → 광고 그룹 2개 만들기
   - `결과화면_배너` (배너)
   - `놓친문제_리워드` (리워드, 보상: "놓친 문제 1개")
2. 발급된 ID를 `apps-in-toss/app/.env` 파일에 넣기 (`.env.example` 참고) → 다시 빌드 → 업로드 → 검수
   - ID만 알려 주시면 제가 넣어서 빌드해 드릴게요.
- 광고 수익은 사업자 등록 없이 시작할 수 있어요 (누적 예상수익 5천 원까지). 이후 정산을 받으려면 사업자 등록이 필요해요.
- **실제 광고 ID로는 테스트하면 안 돼요** (정책 위반). 테스트는 지금처럼 테스트 ID로 해요.

### 문제 추가
- 문제는 `apps-in-toss/app/src/questions/*.json` 에 있어요. 주제마다 26개 → 26주(6개월) 동안 겹치지 않아요.
- 6개월이 지나면 처음 문제부터 다시 나오니, 그 전에 새 문제를 추가해서 번들을 다시 올려 주세요.
- `npm test` 로 문제 형식과 날짜 로직을 검사할 수 있어요.
