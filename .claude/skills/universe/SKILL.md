# 유니버스 — 영상 디렉팀 진입

사용자가 앞으로 만들 영상들의 공용 캐릭터 유니버스다. 이 스킬이 불리면 디렉팀 모드로 들어간다.

## 1. 진입하자마자 할 일

1. `characters.md`(설정집)와 `prompt-blocks.md`(모델용 프롬프트 블록)를 읽는다.
2. 사용자에게 아래 형식으로 짧게 인사하고 무엇을 만들지 묻는다. 길게 설명하지 않는다.

```
🎬 유니버스 디렉팀 대기 중
등장 가능: 무명 · 좀비 아빠 · 서현 · 시율 · 메이드 · 홍길동
무엇을 찍을까요? (예: "무명 vs 홍길동 대결 15초", "서현과 아빠의 재회 30초")
```

사용자가 "유니버스"와 함께 이미 요청을 적었다면 인사 없이 바로 2단계로 간다.

## 2. 디렉팀 파이프라인

| 단계 | 담당 | 산출물 |
|---|---|---|
| ① 기획 | 이 스킬 | 로그라인, 등장 캐릭터, 길이, 톤 |
| ② 스토리·비트 | 이 스킬 | 초 단위 비트 시트 (누가, 무엇을, 감정) |
| ③ 카메라 | `카메라` 스킬 (있으면) | 샷 크기·앵글·무빙·컷 연결 |
| ④ 모델 프롬프트 | 사용자가 고른 모델의 스킬 | 컷별 최종 프롬프트 |
| ⑤ 생성 (요청 시에만) | 연결된 생성 도구 | 실제 이미지·영상 |

- ④ 모델 스킬 매핑: Seedance 2.5 / 씨댄스 → `시댄스25` 또는 `seedance-25-prompting`, Kling 4.0 → `클링4`, Kling 실제 생성 → `kling-ai:kling-ai-generate-video`. 모델이 정해지지 않았으면 한 번 묻는다.
- 해당 스킬이 이 세션에 없으면 같은 원칙으로 직접 작성한다.
- ⑤는 과금 작업이다. 사용자가 생성하라고 명시하기 전에는 프롬프트까지만 만든다.

## 3. 캐릭터 일관성 규칙 (모든 단계에 적용)

1. 프롬프트에 캐릭터가 나오면 `prompt-blocks.md`의 `[ID]` 블록을 **원문 그대로** 넣는다.
2. `[LOCK]` 항목은 연출을 위해서라도 바꾸지 않는다. 특히:
   - 무명은 절대 눈을 뜨지 않는다.
   - 좀비 아빠의 눈은 항상 우윳빛 흰 눈이고, 무협 옷으로 갈아입지 않는다 (사용자가 바꾸라고 하면 예외).
   - 서현의 오른쪽 볼 흉터, 시율의 은백색 사이드 포니테일, 메이드의 앞치마 주머니, 홍길동의 삿갓·지팡이는 유지.
3. 레퍼런스 이미지가 들어가는 모델이면 `sheets/`의 해당 캐릭터 시트를 레퍼런스로 지정하라고 안내한다 (파일 경로를 명시).
4. 능력 연출은 `[FX]` 기본값에서 출발하되, 사용자의 원작 설정을 넘어서는 새 능력은 만들지 않는다.
5. `characters.md`에서 "미정"이거나 "연출 제안"인 내용은 확정 설정처럼 쓰지 않는다. 영상에 꼭 필요하면 사용자에게 묻거나, 이번 영상 한정 가정이라고 밝힌다.

## 4. 설정이 늘어날 때

- 사용자가 새 설정(이름, 관계, 말투, 새 캐릭터, 새 의상)을 정하면 `characters.md`와 `prompt-blocks.md`를 함께 고친다.
- 새 캐릭터는 같은 형식으로 `## 07 …` 항목을 추가하고, 시트 이미지는 `sheets/07_<영문이름>.png`로 저장한다.
- `characters.md` 끝의 "열린 질문"이 답해지면 그 줄을 지우고 본문에 반영한다.

## 5. 출력 형식 (컷 리스트)

```
[영상 제목] · 길이 · 모델
로그라인: …

CUT 01 (0–3s) | 등장: 무명
- 비트: …
- 카메라: …
- 프롬프트: <[ID] 블록> + <행동/환경/카메라/조명>
- 레퍼런스: .claude/skills/universe/sheets/01_mumyeong.png
```
